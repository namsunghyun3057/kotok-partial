# S7. 보조 지표 M2b-융합 (128K, held-out 융합 어절 4,244개)

대상: 한글만으로 된 어절 중 형태소열이 [실질 형태소]* + 융합(VV/VA/XSV/XSA+EP) + [조사·어미]+ 인 어절. 골드 경계 = 융합 형태소 끝(했|다). 정렬 = 바이트 누적 토큰 경계 일치. 본 M2에서 제외된 어절만 대상으로 한다.

| 조건 | M2b-융합 |
|---|---|
| P0 | 12.8% |
| P1 | 100% |
| P2G-30 | 47.0% |
| P2R-30 | 10.6% |
| P2R+-30 | 60.3% |
| P2G-100 | 98.5% |
| P2R-100 | 13.0% |
| P2R+-100 | 84.6% |

P2R은 융합 어절에서 P0 수준(10.6~13.0%)이고, P2R+는 60.3%(k=30)·84.6%(k=100)로 올라 P2G-100의 98.5%에 근접한다. 본 M2b가 보지 못하는 P2R+의 개선이 이 보조 지표에서 드러난다.

## P2G-30 = 47.0%의 원인 (2026-09-08 확인)
- 대상 융합 어절 4,244개는 한글만으로 된 어절이므로 문장 중간형이다. 융합 어간 바로 뒤 어미 표면형 상위: 던(ETM) 923, 다고(EC) 551, 을(ETM) 445, 고(EC) 318, 다는(ETM) 303, 는데(EC) 296, 지만 273, 기 132, 는지 111, 다가 111, 다 110.
- Mecab은 다고·다는·는데·던을 한 형태소로 태깅하며 이들은 상위 30 목록에 없다(100에는 있음). 목록에 있는 어미가 뒤따르는 어절 1,390개(32.8%)는 P2G-30이 전부 자르고 정렬된다. 나머지 2,854개 중 604개는 P0식 우연 정렬. (1,390+604)/4,244 = 47.0%.
- 골드 경계 정의(융합 형태소 끝)와 마킹 단위(형태소 표면형 = 목록 항목)에는 문제가 없다. 지표 유지, 논문 4.4절·부록 표 캡션에 원인 명시.
